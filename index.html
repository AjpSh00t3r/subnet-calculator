How IPv4 subnetting works

An address is 32 bits

Each dotted number is one octet, 8 bits, 0–255. 192.168.10.77 is really one 32-bit number written in four pieces.

The prefix splits it in two

/26 means the first 26 bits name the network and the last 6 bits name a host inside it. The mask is just 26 ones followed by 6 zeros: 255.255.255.192.

Network = address AND mask

A bitwise AND keeps the network bits and zeros out the host bits. That gives the first address of the block, which identifies the network itself.

Broadcast = host bits all set to 1

OR the network address with the inverted mask (the wildcard). The result is the last address in the block, used to reach every host at once.

Counting hosts

With h host bits the block holds 2h addresses. Subtract 2 for the network and broadcast addresses. A /26 has 26 − 2 = 62 usable hosts. /31 links use both addresses (RFC 3021) and /32 is a single host.

Splitting

Borrowing n host bits for the network makes 2n smaller subnets. A /24 split into /26s borrows 2 bits, giving 4 subnets that start every 64 addresses.

How IPv6 is different

128 bits, written in hex

Eight 16-bit groups (hextets) of 4 hex digits. Leading zeros drop and one run of all-zero groups becomes ::, so 2001:0db8:0000:0000:0000:0000:0000:0001 is 2001:db8::1.

Same AND, same OR

Network = address AND mask, last address = network OR inverted mask. Each hex digit is exactly 4 bits, so a prefix that is a multiple of 4 cuts cleanly between digits.

No broadcast, no lost hosts

IPv6 replaced broadcast with multicast, so nothing is subtracted. A block with h host bits has 2h usable addresses.

/64 is the LAN size

Devices build the last 64 bits (the interface ID) themselves with SLAAC, so a LAN is a /64. ISPs usually hand out a /48 or /56, which you split into /64s. A /48 holds 65,536 of them.
